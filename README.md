# Inleiding tot de programmeertaal Java en het Spring-ecosysteem

Deze repository bevat de statische website van de cursus en de werkcolleges (TD) „Inleiding tot de programmeertaal Java en het Spring-ecosysteem“.

## 🔗 Toegang tot de cursus

De cursus is rechtstreeks online te raadplegen op het volgende adres:

👉 **[https://stahe.github.io/nl-java-spring-dec-2015/](https://stahe.github.io/nl-java-spring-dec-2015/)**

---

## 📚 Over dit document

Dit lesmateriaal is bedoeld voor beginnende studenten in een universitaire context. Het combineert theoretische lesstof met praktische oefeningen.

### Leerdoelen

Het belangrijkste doel is om de programmeertaal Java vanuit een **professioneel** perspectief aan te leren. Daarom leunt de cursus sterk op het **[Spring](http://spring.io/)**-framework, een technologie die wordt gebruikt bij de ontwikkeling van **JEE** (Java Enterprise Edition).

Logischerwijs vormt deze module een inleiding voorafgaand aan een gespecialiseerde JEE-cursus.
