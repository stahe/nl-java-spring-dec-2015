    8. [TD]: De laag [metier]

    Trefwoorden: meerlaagse architectuur, Spring, afhankelijkheidsinjectie.

    8.1. Support

     

    De map [support / chap-08] bevat het Eclipse-project van dit hoofdstuk.

    8.2. Maven-configuratie

      

    Het project [elections-metier-dao-jdbc] zal voortbouwen op het project [elections-dao-jdbc-01]. We gaan de jar van dit laatste project in de lokale Maven-repository installeren:

     

    Zodra dit is gebeurd, ziet de Maven-configuratie van het Eclipse-project [elections-metier-dao-jdbc] er als volgt uit:

    8.3. Spring-configuratie

      
    
package elections.metier.config;

import org.springframework.cache.annotation.EnableCaching;
import org.springframework.context.annotation.ComponentScan;
import org.springframework.context.annotation.Import;

@Import({ elections.dao.config.AppConfig.class })
@EnableCaching
@ComponentScan(basePackages = { "elections.metier.service" })
public class MetierConfig {
}
    • regel 7: we importeren alle beans die zijn gedefinieerd in de laag [DAO];
    • regel 8: de cache wordt geactiveerd. De bean [CacheManager] wordt niet opnieuw gedefinieerd, omdat deze al is gedefinieerd in de laag [DAO];
    • regel 9: de laag [métier] definieert nieuwe beans in het pakket [elections.metier.service];

    8.4. De interface [IElectionsMetier]

      

    De laag [metier] zal de in paragraaf 4.2 beschreven interface hebben. We herhalen deze hier:

    
public interface IElectionsMetier {

    public ListeElectorale[] getListesElectorales();

    public int getNbSiegesAPourvoir();

    public double getSeuilElectoral();

    public void recordResultats(ListeElectorale[] listesElectorales);

    public ListeElectorale[] calculerSieges(ListeElectorale[] listesElectorales);

}

    8.5. De implementatieklasse [ElectionsMetier]

      

    Deze klasse implementeert de interface [IElectionsMetier]. De voorgestelde implementatie zal de volgende structuur hebben:

    
package elections.metier.service;

import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.cache.annotation.Cacheable;
import org.springframework.stereotype.Component;

import elections.dao.entities.ListeElectorale;
import elections.dao.service.IElectionsDao;

@Component
public class ElectionsMetier implements IElectionsMetier {

    // het toegangspunt tot de laag [dao], geïnstantieerd door [Spring]
    @SuppressWarnings("unused")
    @Autowired
    private IElectionsDao electionsDao;

    // berekening van het aantal behaalde zetels
  @Override
    public ListeElectorale[] calculerSieges(ListeElectorale[] listesElectorales) {
        throw new RuntimeException("[calculerSieges] not yet implemented");
    }

    // concurrerende lijsten
  @Override
    public ListeElectorale[] getListesElectorales() {
        throw new RuntimeException("[getListesElectorales] not yet implemented");
    }

    // opslag van de resultaten
  @Override
    public void recordResultats(ListeElectorale[] listesElectorales) {
        throw new RuntimeException("[recordResultats] not yet implemented");
    }

    // aantal te verdelen zetels
    @Override
    public int getNbSiegesAPourvoir() {
        throw new RuntimeException("[getNbSiegesAPourvoir] not yet implemented");
    }

    // kiesdrempel
    @Override
    public double getSeuilElectoral() {
        throw new RuntimeException("[getSeuilElectoral] not yet implemented");
    }

}
    • regel 10: de klasse [ElectionsMetier] is een Spring-component;
    • regel 11: de klasse [ElectionsMetier] implementeert de interface [IElectionsMetier];
    • regels 15-16: Spring-injectie van een verwijzing naar de laag [DAO];
    • regels 37 en 44: het aantal te vervullen zetels en de kiesdrempel worden in de cache opgeslagen;

    Te doen: schrijf de klasse [ElectionsMetier]. Gebruik daarbij de commentaren waar die aanwezig zijn. Probeer geen uitzonderingen van het type [ElectionsException] die vanuit de laag [DAO] worden doorgegeven, op te vangen (try / catch). We laten ze doorgaan naar de laag [UI]. Omdat de klasse [ElectionsException] een ongecontroleerd uitzonderingstype is, is het niet verplicht om deze af te vangen met een (try / catch).
