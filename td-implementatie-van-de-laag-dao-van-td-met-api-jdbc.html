    7.5.1. De klasse [ElectionsException]

      

    De klasse [ElectionsException] is beschreven in paragraaf 4.3. We geven de code ervan nogmaals weer:

    
package ...;

import java.io.Serializable;
import java.util.ArrayList;
import java.util.List;

// uitzonderingsklasse voor de applicatie 'Elections'
// de uitzondering is ongecontroleerd

public class ElectionsException extends RuntimeException implements Serializable {

    // serial ID
    private static final long serialVersionUID = 1L;

    // lokale velden
    private int code;
    private List<String> erreurs;

    // constructors
    public ElectionsException() {
        super();
    }

    public ElectionsException(int code, Throwable e) {
        // bovenliggend
        super(e);
        // lokaal
        this.code = code;
        this.erreurs = getErreursForException(e);
    }

    public ElectionsException(int code, String message, Throwable e) {
        // bovenliggend
        super(message,e);
        // lokaal
        this.code = code;
        this.erreurs = getErreursForException(e);
    }

    public ElectionsException(int code, String message) {
        // bovenliggend
        super(message);
        // lokaal
        this.code = code;
        List<String> erreurs = new ArrayList<>();
        erreurs.add(message);
        this.erreurs = erreurs;
    }

    public ElectionsException(int code, List<String> erreurs) {
        // bovenliggend
        super();
        // lokaal
        this.code = code;
        this.erreurs = erreurs;
    }

    // lijst met foutmeldingen van een uitzondering
    private List<String> getErreursForException(Throwable th) {
        // de lijst met foutmeldingen van de uitzondering wordt opgehaald
        Throwable cause = th;
        List<String> erreurs = new ArrayList<>();
        while (cause != null) {
            // de melding wordt alleen opgehaald als deze !=null is en niet leeg is
            String message = cause.getMessage();
            if (message != null) {
                message = message.trim();
                if (message.length() != 0) {
                    erreurs.add(message);
                }
            }
            // volgende oorzaak
            cause = cause.getCause();
        }
        return erreurs;
    }

    // getters en setters
...
}

    Een object [ElectionsException] wordt gekenmerkt door twee gegevens:

    • regel 16: een foutcode;
    • regel 17: een lijst met foutmeldingen die verband houden met de stapel uitzonderingen die zich hebben voorgedaan;
    • de klasse heeft 5 constructors (regels 20, 24, 32, 40, 50);
    • regels 59-76: met de methode [getErreursForException] kunnen de foutmeldingen uit de uitzonderingsstack worden opgehaald;

    7.5.4. De klasse [ListeElectorale]

      

    De klasse [ListeElectorale] is als volgt:

    
package elections.dao.entities;

public class ListeElectorale extends AbstractEntity {

    // velden
    private String nom;
    private int voix;
    private int sieges;
    private boolean elimine;

    // constructors
    public ListeElectorale() {
    }

    public ListeElectorale(String nom, int voix, int sieges, boolean elimine) {
        // ouder
        super();
        // lokale velden
        initNom(nom);
        initVoix(voix);
        initSieges(sieges);
        this.elimine=elimine;
    }

    public ListeElectorale(Long id, Long version, String nom, int voix, int sieges, boolean elimine) {
        // ouder
        super(id, version);
        // lokale velden
        initNom(nom);
        initVoix(voix);
        initSieges(sieges);
        this.elimine=elimine;
    }

    // privé-methoden
    private void initNom(String nom) {
        this.nom = nom.trim();
        if ("".equals(nom)) {
            throw new ElectionsException(10, "Le nom ne peut être vide");
        }
    }

    private void initVoix(int voix) {
        this.voix = voix;
        if (voix < 0) {
            throw new ElectionsException(11, "Le nombre de voix ne peut être <0");
        }
    }

    private void initSieges(int sieges) {
        this.sieges = sieges;
        if (sieges < 0) {
            throw new ElectionsException(12, "Le nombre de sièges ne peut être <0");
        }
    }

    // getters en setters

    public String getNom() {
        return nom;
    }

    public void setNom(String nom) {
        initNom(nom);
    }

    public int getVoix() {
        return voix;
    }

    public void setVoix(int voix) {
        initVoix(voix);
    }

    public int getSieges() {
        return sieges;
    }

    public void setSieges(int sieges) {
        initSieges(sieges);
    }

    public boolean isElimine() {
        return elimine;
    }

    public void setElimine(boolean elimine) {
        this.elimine = elimine;
    }

}
    • regel 3: de klasse is een uitbreiding van de klasse [AbstractEntity];
    • regels 6-9: de klasse slaat de kolommen [NOM, VOIX, SIEGES, ELIMINE] van de tabel [LISTES] op;

    7.6. Spring-configuratie van de laag [DAO]

     

    De klasse [AppConfig] is een Spring-configuratieklasse die de toegang tot de database als volgt configureert:

    
package elections.dao.config;

import org.apache.tomcat.jdbc.pool.DataSource;
import org.springframework.cache.CacheManager;
import org.springframework.cache.annotation.EnableCaching;
import org.springframework.cache.concurrent.ConcurrentMapCacheManager;
import org.springframework.context.annotation.Bean;
import org.springframework.context.annotation.ComponentScan;
import org.springframework.context.annotation.Configuration;

@ComponentScan(basePackages = { "elections.dao.service" })
@EnableCaching
public class AppConfig {

    // constanten
    public final static String URL = "jdbc:mysql://localhost:3306/dbelections";
    public final static String USER = "root";
    public final static String PASSWD = "";
    public final static String DRIVER_CLASSNAME = "com.mysql.jdbc.Driver";
    public final static String SELECT_LISTES = "SELECT ID, VERSION, NOM, VOIX, SIEGES, ELIMINE FROM LISTES";
    public final static String SELECT_CONF = "SELECT ID, VERSION, SAP, SEUILELECTORAL, SAP FROM CONF";
    public final static String UPDATE_LISTES = "UPDATE LISTES SET VOIX=?, SIEGES=?, ELIMINE=? WHERE ID=?";

    @Bean
    public DataSource dataSource() {
        // gegevensbron TomcatJdbc
        DataSource dataSource = new DataSource();
        // toegangscontrole JDBC
        dataSource.setDriverClassName(DRIVER_CLASSNAME);
        dataSource.setUsername(USER);
        dataSource.setPassword(PASSWD);
        dataSource.setUrl(URL);
        // een aanvankelijk geopende verbinding
        dataSource.setInitialSize(1);
        // resultaat
        return dataSource;
    }

    @Bean
    public CacheManager cacheManager() {
        return new ConcurrentMapCacheManager("electionsConfig");
    }
}
    • regels 25-38: de toegang tot BD verloopt via een gegevensbron [tomcat-jdbc]. Dit type gegevensbron is in paragraaf 6.5 gebruikt en uitgelegd;
    • regels 17-23: een reeks statische constanten die toegankelijk zijn voor alle klassen van het project;
    • regel 13: de annotatie [@Configuration] maakt van de klasse [AppConfig] een Spring-configuratieklasse;
    • regel 11: de annotatie [@ComponentScan] geeft aan in welke pakketten Spring-objecten te vinden zijn. Hier gaan we een Spring-object definiëren in het pakket [dao]. De annotatie [@ComponentScan] maakt van de klasse een configuratieklasse, waardoor we de annotatie [@Configuration] niet hoeven toe te voegen;
    • regel 12 schakelt cachebeheer in. Het principe is als volgt:
      • we plaatsen de annotatie [@Cacheable('nom_du_cache')] op een methode M. De 'naam_van-de-cache' is de naam die in regel 41 wordt gebruikt;
      • wanneer methode M voor de eerste keer wordt aangeroepen, worden de resultaten weergegeven en tevens opgeslagen in de cache die door de annotatie wordt aangeduid;
      • wanneer methode M de volgende keren wordt aangeroepen met dezelfde parameters als de eerste keer, wordt deze niet uitgevoerd en geeft Spring alleen de in de cache opgeslagen waarden weer;

    7.7. Configuratie van de logbestanden

    De logbibliotheken worden gedefinieerd door de volgende afhankelijkheid in [pom.xml]:

    
        <!-- Spring Boot-logboekregistratie -->
        <dependency>
            <groupId>org.springframework.boot</groupId>
            <artifactId>spring-boot-starter-logging</artifactId>
</dependency>

    Deze afhankelijkheid levert de volgende bibliotheken op:

      

    De bibliotheek [logback] zorgt voor de logbestanden. Deze wordt geconfigureerd via twee bestanden:

    • [logback.xml] voor de hoofdtak van de code;
    • [logback-test.xml] voor de testtak van de code. Als dit bestand ontbreekt, wordt het vorige bestand gebruikt;

    Deze twee bestanden moeten zich in de map [Classpath] van het project bevinden. Daarom worden ze in de map geplaatst:

    • [src / main / ressources] voor de hoofdtak van de code;
    • [src / test / ressources] voor de testtak van de code;

    De inhoud van de bestanden is hier hetzelfde:

    
<configuration> 

  <appender name="STDOUT" class="ch.qos.logback.core.ConsoleAppender"> 
    <!-- encoders krijgen  standaard het type toegewezen
         ch.qos.logback.classic.encoder.PatternLayoutEncoder -->
    <encoder>
      <pattern>%d{HH:mm:ss.SSS} [%thread] %-5level %logger{36} - %msg%n</pattern>
    </encoder>
  </appender>

  <!-- logniveau-controle -->
  <root level="info"> <!-- info, debug, warn -->
    <appender-ref ref="STDOUT" />
  </root>
</configuration>

    Alles gebeurt op regel 12, waar het gewenste informatieniveau wordt ingesteld:

    • [debug]: het meest gedetailleerde niveau;
    • [off]: geen logbestanden;
    • [info]: het normale logniveau;
    • [warn]: hetzelfde als niveau [info] plus de waarschuwingsberichten (warning). Deze berichten duiden op een mogelijke fout;

        } catch (ElectionsException e) {
            System.out.println("Les erreurs suivantes se sont produites lors de la lecture des tables ----------");

        }

    // privé-methoden ------------------
    private static List<String> getErreursForThrowable(Throwable th) {
        // we halen de lijst met foutmeldingen van de uitzondering op
        Throwable cause = th;
        List<String> erreurs = new ArrayList<>();
        while (cause != null) {
            // we halen het bericht alleen op als het !=null is en niet leeg
            String message = cause.getMessage();
            if (message != null) {
                message = message.trim();
                if (message.length() != 0) {
                    erreurs.add(message);
                }
            }
            // volgende oorzaak
            cause = cause.getCause();
        }
        return erreurs;
    }
